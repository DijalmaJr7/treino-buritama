Zonas

Isto é uma cópia para consulta

Mudar não dá, e não adiantaria: esta tabela não manda em nada. Os números de verdade ficam em dois lugares, e cada um muda uma coisa diferente.

Alvos de FC (Z2 HR): quem traduz a zona em batimentos, na hora de mandar para o relógio, é o Intervals.icu em Settings → Zones. É lá que se muda.

Alvos de ritmo (5:20/km, 2:30/100m): vão literais do plano para o relógio. Mudar no Intervals.icu não altera nada — tem que mudar no plano, no computador.

No computador, python sync.py zonas lê as zonas da sua conta e avisa se elas divergem desta tabela.

Conexão

A chave fica guardada só neste aparelho. Ela não vai para o GitHub nem para lugar nenhum — o app fala direto com o Intervals.icu.
